SMART WATER BOTTLING FACTORY - WEB VERSION

Run on Windows:
1. Install Python 3.
2. Open CMD inside this extracted folder.
3. Run: py -m pip install -r requirements.txt
4. Run: py app.py
5. Open http://127.0.0.1:5000 in Chrome or Edge.

The website includes start, pause, reset, sensor monitoring, test faults,
automatic rule-based control, production count and event log.
It is an educational simulation, not connected to real industrial equipment.
